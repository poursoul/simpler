# 2026-07-30 shared Claim 候选收窄负面实验留档

## 结论

本目录保存两份 A5、B256、shared TensorMap、完整 atomic/DCCI 泳道，
用于对照原始 Claim 合同与非等价候选收窄实验。

`12/8/8` 确实把单次完整泳道的 Submit 从原始合同历史最优样本的
`2421.040 us` 降到 `1750.044 us`，减少 `670.996 us（27.71%）`。
这个性能结果是真实采集结果，但不能作为可保留优化：它把大量原本有资格
成为 winner 的 worker 从 true loser 改成 `not_attempted`，改变了 Claim
合同和 winner 候选集合。

## 如何解释性能结果

本次结果证明的是：当前 B256 中 Claim 原子竞争是明显的性能影响因素；
直接减少 ClaimMax 数量和同一原子线上的竞争者，能够显著缩短完整 Submit。

它没有证明 `12/8/8` 与原协议等价：

- 原始 Alloc 的 96 核、QK/PV 的 32 个 AIC、SF/UP 的 64 个 AIV 都是
  合法 winner 候选；
- `12/8/8` 通过 `worker_id` 与 cursor shard 的额外映射取消了大部分
  worker 的竞争资格；
- 固定 B256 仍得到唯一 winner，只能证明该用例功能闭合，不能证明任意
  到达顺序、阻塞状态和任务图下与原合同一致；
- 因此 `27.71%` 是“改变工作量和候选合同后的性能差”，不是等价 loser
  优化收益。

另有无泳道 `perf-clock` 记录：候选收窄实验中的最低单样本为
`1549.284 us`，来自 `24/8/8`，并非本目录 `12/8/8` 泳道对应的同一次
执行。两种构建的绝对时间不能互减；本目录只用完整泳道解释工作分布。
